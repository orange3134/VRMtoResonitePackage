# Resoniteの検出と起動時セットアップ

GUIは起動時に、更新確認が完了してから `ResoniteLocator.Locate` を実行し、
検出成功後に起動引数による変換へ進む。
検出できない場合はセットアップ画面を表示する。CLIの検出・終了コードは変更しない。

- 判定は既存仕様どおり、候補フォルダの `FrooxEngine.dll` の存在確認。
  DLL一式やバージョン互換性の検証ではない。
- 候補順はGUI設定、`RESONITE_PATH`、EXE横の `resonite-path.txt`、
  既定Steamフォルダ、レジストリと `libraryfolders.vdf` から列挙したSteamライブラリ。
- 明示的なGUI設定が無効な場合は自動検出へフォールバックしない。
  案内画面で設定パスを示し、設定の修正または空欄に戻すよう案内する。
- 未検出は未インストールの証明ではないため、「見つかりません」と案内する。
- Steamリンクは利用者のクリックで既定ブラウザーにストアページを開く。
  起動だけでリンクを開いたり、インストールを実行したりしない。
- 「設定」から既存の設定画面を開き、閉じた後に再検出する。
  「再確認」はSteamでのインストール後などに再検出する。
- 「後で」、Esc、閉じるボタンではメイン画面を残し、この起動時の自動変換は行わない。
  更新を適用する場合は元の入力ファイルを引き継いで再起動し、旧プロセスでは案内しない。
  更新なし・更新辞退・更新確認失敗・更新適用失敗の場合はその後に検出する。
  更新確認が無効または自己更新不可の場合はすぐに検出する。
  設定変更や後からのファイル投入は可能。設定を恒久的に無効にする機能ではない。
- GUIの案内には検出時の例外メッセージを追加表示しない。`FrooxEngine.dll` などの
  内部情報を省き、Steamからのインストールと設定での指定を案内する。

## Windowsでの手動回帰確認

日本語・英語それぞれで確認する。設定と環境変数は確認前に控え、確認後に戻す。

1. 有効なResoniteパスを設定して起動する。案内が出ず通常画面へ進む。
2. Resoniteを自動検出できる環境で設定を空にする。同じく案内が出ない。
3. 存在しない明示パスを設定して起動する。設定パスの問題を示し、Steamの別の
   有効なインストールを勝手に利用しない。
4. 「設定」で有効なパスへ修正して保存する。再検出が通り通常画面へ進む。
   キャンセルまたは無効パスの保存では案内に戻る。
5. 未検出環境で起動する。未インストールと断定せず、インストールと設定の両方を案内する。
   日本語では「インストール済みのResoniteが見つかりませんでした。Steamからインストールしてください。インストール済みの場合は設定で指定してください。」と表示し、例外詳細を追加表示しない。
6. Steamリンクはクリックするまでブラウザーが開かない。クリック時のURLは
   `https://store.steampowered.com/app/2519830/Resonite/`。
7. 案内を開いたままインストールや外部設定を修正し「再確認」。成功時のみ先へ進む。
8. 「後で」、Esc、×でアプリが終了せず設定を開ける。入力ファイル付き起動でも
   不足状態で変換が始まらない。
9. 有効なインストールと入力ファイル付きで起動した場合は従来どおり変換が始まる。
10. CLIの未検出エラーと終了コード3が従来どおりである。

## 起動順の回帰確認

- 更新なし／辞退／確認失敗／ダウンロード失敗の各場合で、更新処理が完了してから
  セットアップ案内が1回だけ表示されること。
- 更新適用・再起動が成功する場合、旧プロセスにはセットアップ案内を出さず、
  元の入力ファイルを再起動先へ引き継ぐこと。
- 更新確認を無効にした場合と自己更新不可の場合も、検出を省略しないこと。
- セットアップ案内を閉じた場合、入力ファイルの自動変換を開始しないこと。

## 変換開始時の検出

ファイル付き起動と後からのドロップは、共通の `StartConversion` で検出する。
起動時チェックを重ねて呼ばず、入力ファイルの解析・アバター列挙・材質確認より先に
セットアップ案内を出す。「後で」等で閉じた場合は入力解析にも変換にも進まない。
成功した検出パスはDLL解決設定と変換子プロセスへ引き継ぐ。
入力解析中の例外も既存の変換エラー画面で処理する。

追加の手動確認:
- 未検出状態で案内を閉じ、正常なVRM／unitypackage／prefabをそれぞれドロップする。
  解析表示・アバター選択より先に案内が出て、閉じれば解析を始めないこと。
- 壊れた入力ファイルでも未検出の案内が先になること。
- ファイル付き起動でセットアップ案内が二重表示されないこと。
- 設定から有効なパスに直すと同じ変換要求が続行すること。
- 検出成功後に壊れた入力の解析が失敗した場合、エラー画面から設定を開けること。
